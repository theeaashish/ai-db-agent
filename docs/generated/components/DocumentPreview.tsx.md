# DocumentPreview Component

The `DocumentPreview` component is a UI component designed to render structured reports generated by the AI chat interface. It provides an interactive, accordion-style view of report sections and includes functionality to download the report as a JSON file.

## Purpose
This component serves as the primary visual interface for the `generate_report` tool output. It transforms raw report data (title, summary, sections, and metadata) into a polished, readable document format within the chat stream.

## Key Features
*   **Interactive Accordion:** Users can expand or collapse individual report sections to manage information density.
*   **JSON Export:** Includes a "Download" button that generates and triggers a browser download of the report data as a `.json` file.
*   **Metadata Display:** Shows the generation date and a unique document ID for tracking.
*   **Data Visualization:** If a section contains raw data, it is rendered in a formatted, scrollable code block.
*   **Responsive Design:** Built with Tailwind CSS, featuring a glassmorphism aesthetic and smooth entry animations.

## Component API

### Props
| Prop | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | The main title of the report. |
| `summary` | `string` | A brief overview of the report's contents. |
| `sections` | `Section[]` | An array of objects containing `heading`, `content`, and optional `data`. |
| `generatedAt` | `string` | ISO timestamp of when the report was created. |
| `documentId` | `string` | Unique identifier for the report. |

### Section Interface
```typescript
interface Section {
  heading: string
  content: string
  data?: any // Optional raw data to be displayed in a code block
}
```

## Usage
This component is typically used within the chat interface (`app/page.tsx`) when the AI tool execution returns a `generate_report` result:

```tsx
import { DocumentPreview } from "@/components/DocumentPreview"

// Inside your chat message rendering logic:
if (toolName === "generate_report") {
  return <DocumentPreview {...(result as any)} />
}
```

## Dependencies
*   **UI Components:** Uses custom components from `@/components/ui/` (Card, Button, Badge).
*   **Icons:** Uses `lucide-react` for visual indicators (FileText, Download, Calendar, etc.).
*   **Styling:** Relies on Tailwind CSS for layout and animations.
